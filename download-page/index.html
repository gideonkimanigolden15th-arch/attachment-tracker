Attachment Tracker Windows

Upload your weekly logbook and face photo, keep your streak, and turn the photo into a social media card.

Download for Windows Portable version (zip)

Windows 10 or 11. The installer adds a Start menu entry and an optional desktop icon. Nothing else to install.

Windows may say "Windows protected your PC". The app is not signed with a paid certificate yet. Click More info, then Run anyway. Only do this for a file you downloaded from this page.

Install in three steps

  1. DownloadPress Download for Windows. The file is called AttachmentTracker-Setup.exe.
  2. Run itOpen the file and follow the installer. It does not need administrator rights.
  3. Open itStart Attachment Tracker from the desktop icon or the Start menu. The first time, choose New student and add your name and registration number.

Each week

UploadPhoto of your filled-in logbook page first, then a face photo holding a pen. Any day of the week counts. Friday is streak day.
StudioTurn your face photo into a card with themes and templates, sized for social media.
My ProgressYour weekly completion graph and streak.
SupervisorPIN-protected. Shows every student's progress and the photos they submitted.

Where your data lives

Photos and the database are stored in Documents\AttachmentTracker on your computer. Uninstalling the app does not delete them. The Backup & Restore tab prepares the folder for Veeam backups.

Moving to another computer: install the app there and copy that folder across.

Prefer to run it from the source code? View it on GitHub. Needs Python 3.10 or newer.
